# 🎓 辽宁学位英语 · 每日轻松学

一个专为**成人本科学士学位英语考试（辽宁）**设计的轻量学习网站。

## ✨ 功能

- 📅 **每日学习**：每天一组核心词汇 + 一条语法 + 一篇小阅读 + 配套练习，10分钟轻松学
- 📚 **单词本**：核心/高频/进阶分类，按天分组，带音标、词性、例句
- 📖 **语法库**：从零到考试的基础语法图文讲解
- ✍️ **真题练习**：单项选择、完形填空、阅读理解、翻译，带答案解析
- 📝 **作文模板**：观点类议论文万能模板 + 常考话题素材
- ✅ **打卡系统**：学习进度保存在浏览器本地（localStorage）

## 🚀 使用方式

纯静态网站，无需服务器。直接打开 `index.html` 即可使用，或部署到任意静态托管（GitHub Pages / Netlify / Vercel）。

## 📁 文件结构

```
yyzx-site/
├── index.html    # 主页面
├── style.css     # 样式
├── data.js       # 学习内容数据（单词/语法/阅读/练习/作文）
└── app.js        # 交互逻辑（打卡、答题、渲染）
```

## 📝 内容扩展

学习内容都在 `data.js` 中，直接往对应数组里添加即可：
- `WORD_DAYS`：添加每天的单词组
- `GRAMMAR`：添加语法讲解
- `READINGS`：添加阅读文章（英+中）
- `PRACTICE`：添加练习
- `WRITING`：添加作文模板

坚持每天10分钟，顺利通过学位英语考试！💪
